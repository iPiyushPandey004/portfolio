# theme_old — previous portfolio theme

This folder stores the pre-orange theme styles from before the Phase 5 visual refinement. It is intentionally retained as a rollback reference and is not imported by the Angular application.

If the user later asks for `theme_old`, restore the files in this folder to their matching paths under `src/` (global `styles.css` and the listed component CSS files), then rebuild. The current orange theme is the active theme.
